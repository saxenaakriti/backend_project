Backend Python & Flask Architecture

This project is built using Python 3 and Flask with an SQLite database backend.

Backend REST API Endpoints:

  • POST /api/reports — Submit a new anonymous report (JSON payload: category, description, optional evidence_url). Returns generated tracking ID.
  • GET /api/reports/<tracking_id> — Fetch report status and moderator remarks by tracking code.
  • GET /api/moderator/reports — Retrieve all reports (supports ?category= and ?status= filters).
  • POST /api/moderator/update/<id> — Update report status and add moderator notes.
  • GET /api/health — Health check endpoint returning backend status.

Python Project Files:

  • app.py: The main Flask server with all route handlers.
  • database.py: SQLite database functions for creating tables, inserting, updating, and querying reports.
  • templates/index.html: Simple HTML/CSS frontend.
  • EXPLANATION.md: Project explanation document explaining how the backend was created.
